## Freight Route Price Terminal Engine for International Shipping.

Problem: Small and medium-sized businesses that import/export goods struggle to compare sea freight routes, shipping companies, prices, affected routes, and route-specific disruptions in one place, for their desired product or produce.

Target Users:

Manufacturers
Farmers
Clothing brands
E-commerce sellers
Import/Export businesses
Procurement teams
Any entity that desires to buy from abroad or sell to parties abroad.

The Minimum Viable Product (MVP):
A web-based freight route terminal showing:
world map (moveable by user’s mouse, zoom in and out features) 
route lines between ports/countries (user can hover over for more info)
colour-coded price movement (in last week, days etc - adjustable timeframe)
red = price increase
green = price decrease
grey = stable/unknown
search/filter by product category (user can filter for vehicles if they import/export vehicles)
origin and destination filters (user can filter for vehicles from Dubai to UK)
side panel with carriers, route, estimated price, transit time, and price movement (once user applies filters, side panels show shipping carrier info for user)
The following items are NOT in the MVP product and will be added later on: payments, user accounts, real carrier integrations, AI chatbots, live bookings, customs automation, full production-grade pricing accuracy, live calls and note taking.
Data Sources for MVP:
Augmented Data
Mock Data Source
Kaggle Dataset
Seeded Dataset
Live data and web-scraped data will be added in v2 of the software terminal.
